# Expense Tracker

## Description

A command-line expense tracker built in Python that allows users to record expenses, search transactions by category, generate monthly summaries, and save data to a CSV file.

## Features

- Add new expenses
- View all expenses
- Search expenses by category
- Generate monthly spending summaries
- Save expenses to a CSV file

## Skills Demonstrated

- Python
- Functions
- Loops
- Dictionaries
- Lists
- CSV file handling
- Input validation
- Menu-driven applications

## How to Run

1. Open the project in Python.
2. Run `expense_tracker.py`.
3. Follow the menu prompts.
